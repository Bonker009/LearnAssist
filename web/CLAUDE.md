# CLAUDE.md — web/ (Next.js)

Next.js 16 (App Router) with React 19, Tailwind v4, shadcn (`base-nova` style on `@base-ui/react`, not Radix), motion and Recharts. The frontend talks **only** to the Spring Boot API. The repo-wide architecture and design-system summary are in `../CLAUDE.md` and `../README.md`.

`AGENTS.md` is regenerated by `next dev`, so don't edit it. Put web guidance in this file.

## Commands

```bash
npm run dev     # :3000 (the API's CORS must allow this origin; see ../CLAUDE.md)
npm run build   # type-check + build; this is the frontend's test
npm run lint    # eslint (flat config, eslint-config-next)
npx shadcn@latest add <name>             # official primitives → src/components/ui
npx shadcn@latest add @magicui/<name>    # registries are configured in components.json (@magicui, @blocks-so)
```

There is no unit-test setup.

## Structure

- Routes (`src/app`): `/` and `/c/[id]` both render `<ChatApp>` (keyed by id), plus `/dashboard` and `/sign-in`. Pages are thin server components. The app itself is client components.
- `src/lib/api.ts`: the only HTTP client (`api.*`). It sends the JWT from `localStorage` (`learnassist.token`) as a Bearer token and turns failures into `ApiError(status, message)`, reading the message from the Spring `{message}` body. Uploads use XHR so they can report progress: the flow is presigned PUT straight to RustFS, then `ingest`, then poll the document until its job finishes. New endpoints go here, and their types go in `src/lib/types.ts`, matching the Java DTO records.
- `components/auth-provider.tsx`: `useAuth()`. `theme-provider.tsx` wraps next-themes with the `.dark` class.
- `components/chat/`: `chat-app.tsx` holds conversation state and orchestration. The rest are `chat-sidebar`, `composer` (attachments, + menu, drop zone, voice input via `hooks/use-voice-recorder.ts` → `/api/speech/transcribe`), `message-list`, `resource-panel` and `library-dialog`.
- `components/quiz-panel.tsx`, `flashcards-panel.tsx`, `slides-panel.tsx`: the Quiz, Cards and Slides tabs of the resource panel. Slides polls the deck while it generates and embeds the built Slidev site in an iframe (`apiUrl(viewPath)`). Its PDF and `slides.md` links are presigned for 15 minutes, so they are re-fetched on click.
- `components/citation.tsx`: **the single renderer for every source reference** (slide, page, section or timestamp chip) in chat, quiz review and summaries. It's a button that drives the `SourceViewer` already on screen (PDF page, text-reader section, media seek) through the `NavigateHandler` / `SourceViewerHandle` refs. It never navigates the page. New source kinds are handled here, in one place.
- `components/ai-orb.tsx`: CSS-only animated presence (styles are under "AI presence" in `globals.css`). It must respect reduced motion. Don't reintroduce WebGL.
- `components/ui/`: shadcn and registry components (ElevenLabs `live-waveform`/`shimmering-text` were copied in from raw registry JSON). Editing them is fine because they're owned source.

## Styling rules

- Use tokens from `src/app/globals.css`: primitive → semantic → component. Components use **semantic** tokens (`--color-surface`, `--color-citation`, …) or their shadcn aliases. Never use raw hex or palette classes.
- Dark mode redefines semantic tokens under `.dark`, so don't write `dark:` variants.
- Base CSS goes in `@layer base`, because unlayered rules beat every Tailwind utility. Font stacks are written out, since `@theme inline` doesn't emit `var(--font-*)`.
- Citations keep their own amber hue. Brand blue (`--color-primary`) is for actions, and red (`--color-emphasis`) is for secondary emphasis.
- Khmer: set `lang="km"` on Khmer text (Kantumruy Pro is applied automatically). Use `font-display-km` (Dangrek) for display titles, and put the Khmer line first in bilingual titles. `hasKhmer()` is in `lib/utils.ts`.
- Motion: 150–250 ms, ease-out, no bounce.

## Gotcha

`NEXT_PUBLIC_API_BASE_URL` is inlined at **build** time. In `docker-compose.yml` it's set as a runtime `environment:` value for the `web` service, which has no effect on the built bundle. The image falls back to `http://localhost:8081`. To point a container build somewhere else, pass it as a build arg or env var during `npm run build`.
